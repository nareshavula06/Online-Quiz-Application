The Online Quiz Application is a Flutter-based mobile application designed to provide students with an interactive, convenient, and efficient platform for participating in online quizzes. The main purpose of this project is to replace traditional paper-based quiz systems with a digital solution that allows students to attend quizzes anytime and anywhere. The application provides an easy-to-use interface through which students can log in, select quizzes, answer multiple-choice questions, and receive their results immediately after completing a quiz.

The application is developed using Flutter and Dart, which enables the development of a responsive and user-friendly mobile application. Firebase can be integrated as the backend to provide secure authentication, cloud database services, and storage. Students can create an account or log in using their credentials. After successful authentication, they can access available quizzes categorized according to subjects or topics. Each quiz contains a set of multiple-choice questions with predefined options and a time limit. A countdown timer helps students manage their time while answering questions.
